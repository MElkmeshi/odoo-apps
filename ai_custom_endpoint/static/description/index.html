AI Custom Endpoint

Run Odoo's AI features against any OpenAI-compatible gateway

Odoo's AI module has its LLM endpoints hardcoded, so it can only ever talk to OpenAI or Google. This module reads them from settings instead — which is all it takes to point the entire AI stack at a gateway you control.

Point Odoo anywhere

LiteLLM  ·  vLLM  ·  OpenRouter  ·  Azure OpenAI  ·  a self-hosted proxy  ·  a private mirror

Anything that speaks the OpenAI protocol. Set the base URL under Settings → AI → Providers and Odoo's AI agents, prompts and RAG sources go to it instead of api.openai.com.

What you get

Your own models in the dropdown

Add any models your gateway routes — Claude, Llama, Mistral, a fine-tune — and they appear in the AI agent's model list alongside Odoo's built-in ones. The list can be fetched from the gateway itself rather than typed by hand.

Keep your data in your infrastructure

Point Odoo at a gateway inside your own network and prompts, documents and embeddings never leave it. Useful where sending customer data to a third-party API is not acceptable.

Configure in Settings, not in code

A normal settings page for the base URL, key and models. Everything is stored in system parameters, so it can equally be set by script or during deployment.

Inert until you configure it

Every setting is optional and nothing changes on install. Leave the base URL empty and Odoo behaves exactly as it does today; clear it later and it goes straight back.

What your gateway must serve

Odoo drives chat through the OpenAI Responses API (POST /responses) — not /chat/completions — and RAG embeddings through POST /embeddings. A gateway must serve those exact routes. Many OpenAI-compatible proxies implement only /chat/completions; those will not work until they add /responses.

Worth checking before you install — it is the one thing that decides whether a given gateway is usable.

Security note

Your API key is sent to whatever host you configure, so a mistyped address hands the key to whoever answers it. Use HTTPS and a host you control. Only the system administrator can see or change these settings.
