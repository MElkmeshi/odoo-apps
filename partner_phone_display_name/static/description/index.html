Phone in Contact Name

Tell two contacts with the same name apart, without opening either one

Three contacts called “Ahmed” in a dropdown look identical. This module puts the phone number next to the name, so the right one is obvious.

Ahmed Saleh   →   Ahmed Saleh (01001112201)

What it does

Everywhere a contact is shown

Contact selectors, list views, kanban cards, and the “Customer” field on every document. Wherever Odoo prints a contact's name, the number comes with it.

Styled like Odoo's own

In dropdowns the number is rendered the way Odoo renders a contact's email or VAT — as secondary text beside the name, not jammed into it.

Contacts without a phone are untouched

No trailing dash, no empty brackets. A contact with no number displays exactly as it always did.

No fields, no settings

Adds no columns and no configuration. Install it and it works; uninstall it and names go back to normal.

Before you install

This changes display_name, which is what Odoo prints for a contact everywhere — including quotations, invoices, delivery notes and the recipient name on outgoing email. That is the point of the module, but it does mean customer phone numbers will appear on documents you send out.

If you only want the number in selectors and not on printed documents, this is not the right module.

Works well with

Partner Phone (Egypt) — stores every Egyptian mobile in one canonical form, keeps it unique, and finds a contact by number typed any way. Independent of this module; install either or both.
