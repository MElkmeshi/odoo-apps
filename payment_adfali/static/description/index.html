Adfali Payment Provider

Take Adfali mobile wallet payments in Libya — on the checkout page, without leaving it

The customer types their mobile number, Adfali texts them a 4-digit PIN, they type it in, and the order is paid. No redirect to a gateway page, no return URL to configure, no webhook to expose. It is an ordinary Odoo payment provider: it works anywhere payment works — eCommerce checkout, customer portal invoices, subscriptions and payment links.

How a payment goes through

1 Customer picks Adfali at checkout and enters their mobile number.
2 Odoo opens the payment with Adfali. The transaction becomes Pending.
3 Adfali sends the customer a 4-digit PIN by SMS.
4 The customer enters the PIN. On acceptance the transaction is set Done and the order confirms.

What you get

Errors the customer can act on

A wrong service password, a wrong merchant PIN, an amount over the wallet limit, an unknown mobile number and an insufficient balance are each reported as their own message, in the customer's language. A refused payment leaves the transaction in draft, so the customer can correct their number and try again on the same page.

Mobile numbers, however they are typed

0912345678, 912345678 and +218912345678 are all sent to Adfali as the same international number. Customers do not have to guess the format, and you do not field the support call when they guess wrong.

Credentials kept out of reach

The merchant PIN and service password are restricted to Settings administrators and are never rendered to the customer's browser. Gateway responses can echo merchant credentials, so on an API error the body is written to the server log and only a generic message reaches the page.

A failed line is never a lost payment

If the network drops while the PIN is being confirmed, the transaction stays pending and retryable rather than being marked failed — a payment Adfali may have taken is not silently written off. Only a PIN that Adfali answers and rejects moves the transaction to error.

Setting it up

Go to Invoicing › Configuration › Payment Providers, open Adfali, and fill in the four values Adfali issues you: the API Base URL, your Merchant Mobile, your Merchant PIN and your Service Password. Set the provider to Enabled and publish it. That is the whole configuration.

Before you install

You need a merchant account with Adfali and the API credentials issued with it. This module is the Odoo side of that integration; it does not obtain the account for you.

Payments are taken in Libyan Dinar (LYD) only, the sole currency the gateway accepts. The wallet does not support refunds, saved payment methods, express checkout or manual capture through the API, so those Odoo features stay off for this provider — refunds are handled outside Odoo.

Adfali returns no transaction identifier of its own. The gateway session id is recorded as the transaction's provider reference, and it is what support uses to reconcile an Odoo transaction against the gateway.
