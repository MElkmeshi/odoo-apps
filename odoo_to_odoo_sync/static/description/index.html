Odoo to Odoo Sync

Copy another database's records into this one — merged, not duplicated

Point it at another Odoo database of the same version, press Load Models and Sync All. Every model that has records there is copied here, in the order its links need, and matched against what this database already holds.

What you get

Run it again safely

Every copied record keeps an External ID pointing back at the source, so a second run updates instead of creating, and Sync Changes only pulls what changed since the last run.

Links survive

Models are ordered by what they point to. Links that can only be set once both sides exist — a partner's parent, a posted entry's state — are restored in a second pass. Company-specific values are copied per company.

Built for Odoo.sh

Runs as a background job in short resumable chunks, committing as it goes. A run that stops can be resumed from where it was.

A log you can act on

Each run lists what it created and updated, and for every record it could not copy, the reason: a missing link, a constraint, a field it had to leave empty.

Before you run it

Both databases must run the same Odoo version with the same modules installed. The API key's user needs read access to everything you want copied, in every company.

Records are merged: source values overwrite matching records here, and nothing here is deleted. Try it on a staging branch first.
